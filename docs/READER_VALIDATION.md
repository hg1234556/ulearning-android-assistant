## 代码验证

91 项自动化测试通过，并在本机 Python 3.12 和 3.14 运行验证。包含原有设备与导出功能、本地 OCR 输入与错误处理、书名页码区域、分辨率变化、单次点击后置核对、首页末页边界、跳页/换书、断连、取消和本地计时。

走神功能测试覆盖：多条件识别暂停、唯一中央按钮、普通“继续学习”不误判、只发送一次恢复点击、恢复前后书名及页码变化、超时不重试、取消不点击、禁用恢复、次数限制、暂停不累计阅读时间，以及已发送翻页但页码未确认时不自动追加恢复点击。另有回归测试确保 OCR 超过总时限时不累计超时，外部改变页码后停止。GUI 和 CLI 的模拟恢复调用也已核对。
